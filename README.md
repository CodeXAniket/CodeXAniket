## 🚀 Featured Projects

### 🩺 [SQL Query Doctor](https://github.com/CodeXAniket/sql-query-doctor) &nbsp;·&nbsp; [Live Demo](https://sql-query-doctor.vercel.app)
A web SQL performance analyzer that parses **4 dialects** and flags **15+ anti-patterns**, renders cross-engine
`EXPLAIN` plans as one **D3.js** tree, and runs a real **in-browser PostgreSQL** playground (PGlite / WebAssembly).
Suggested indexes cut median query time **1.2 s → 25 ms** on a 500K-row benchmark · 120+ Vitest tests.

### 🛰️ [CipherLink — P2P Encrypted Messenger](https://github.com/CodeXAniket/CipherLink) &nbsp;·&nbsp; [Live Demo](https://cipherlink.duckdns.org)
A browser-to-browser messenger where text, photos and videos (**up to 100 MB**) travel **directly** over
DTLS-encrypted **WebRTC** DataChannels — the signaling server never sees messages. Identity is secured with
**non-extractable ECDSA device keys** and **SHA-256 safety numbers**. Deployed on **AWS EC2** behind Caddy.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black) ![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white) ![WebRTC](https://img.shields.io/badge/WebRTC-333333?style=flat-square&logo=webrtc&logoColor=white) ![WebSocket](https://img.shields.io/badge/WebSocket-010101?style=flat-square&logo=socketdotio&logoColor=white) ![AWS](https://img.shields.io/badge/AWS%20EC2-FF9900?style=flat-square&logo=amazonaws&logoColor=white)

### 👁️ [VisionGuard AI — Object Detection Platform](https://github.com/CodeXAniket/VisionGuard_AI_object_detection)
A surveillance platform: a React UI, a Node/Express API and a **Python YOLOv8** service detecting **80 classes**
in live webcam frames at **~150 ms/frame on CPU**. A debounced event pipeline stores snapshots in private
**AWS S3** (presigned URLs) with metadata in MongoDB, behind **15 JWT-secured REST APIs** and 90+ tests.
